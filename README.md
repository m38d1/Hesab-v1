# حساب من

برنامه حسابداری شخصی فارسی (PWA) — شمسی، آفلاین، بدون سرور. داده‌ها فقط در مرورگر خودت می‌ماند.

- تقویم شمسی، چند حساب، بودجه، اهداف، وام و اقساط، دارایی‌ها، طلب و بدهی، اشخاص
- ثبت از روی پیامک بانک، پنهان‌سازی مبالغ
- خروجی CSV برای اکسل و پشتیبان‌گیری
- قابل نصب روی گوشی و کارکرد آفلاین
